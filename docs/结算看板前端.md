# 上局结算看板 · 前端说明

适用：木桌前端自 `habitrain_core 2.0.31` 起；动态扇形剖切自 `2.0.33` 起；事件特写与托盘边界截断自 `2.0.34` 起；手动播放、无人机轨迹与视频导出自 `2.0.35` 起（客户端与服务端请使用相同版本）。后端数据流见交接文档；本文描述前端呈现、木桌显示设置与验收。

## 外观与布局

- 地面方块（`y+0`）：平整的桃花心木拼花桌面、四根木腿、桌边围板与细黄铜镶边；桌下留空，顶面高 1 格（`wathe` 原生纹理，四向朝向，正面朝放置者）。保留原方块 ID，旧存档中的看板直接使用新外形。
- 方块上一层（`y+1`）：正方形的「列车木质镶铜沙盘底座」。默认边长为 6.85 格（地图长边 6.25 格，两侧各留 0.3 格），随每张桌子的设置等比缩放，待机、加载、播放时不改变。地图保持原比例，开播以保存的地图长边为准；地图 Z 向更长时自动转 90°，使列车始终横在铭牌前方。
  - 桃花心木人字拼底板、乌木外框 + 内沿黄铜饰条、四角黄铜包角与铆钉、底部微型枕木与双轨托架；`wathe` 纹理缺失时回退原版木纹/金块并染色。
  - 正前方斜置 Art Deco 黄铜铭牌：地图名、模式、翻牌式 `mm:ss/mm:ss` 时钟、当前阶段与进度条；地图仍在补齐时显示 `present/total`。
  - 木桌四角到沙盘底部有暖金色全息承托光束，沿光束流动的小光点。调整显示位置时，光束仍从实际桌面连接到沙盘。
- 裁剪：不走方块实体渲染，按已加载看板索引在 `AFTER_TRANSLUCENT` 对「木桌 + 沙盘 + 荣誉屏」整体做视锥裁剪；包围范围随尺寸、高度、偏移和旋转变化；距木桌 48–64 格渐隐，超过 64 格不提交；24 格外不提交铆钉、名牌、火花等细节；最多同时绘制最近 4 块。

## 每张木桌的显示设置

创造模式下对木桌 **Shift + 右键** 打开设置界面（手持方块或工具也可）。

| 项目 | 范围 | 默认 | 按钮步长 |
| --- | --- | --- | --- |
| 地图长边 | 1–32 格 | 6.25 格 | 0.25 格 |
| 离桌面高度（桌面至地图底部） | 0–16 格 | 0.25 格 | 0.25 格 |
| 左右偏移 / 前后偏移 | 各 -16–16 格 | 0 格 | 0.25 格 |
| 旋转 | -180°–180° | 0° | 15° |

- 可直接输入数值；尺寸保持长宽高比例，沙盘、轨迹、人物与荣誉屏采用同一变换。正偏移沿桌子朝向向右、向前。
- 修改即时预览；保存后服务端同步给观看者，取消或 Esc 撤销未保存的显示修改。恢复默认仍需保存。
- 每张桌子独立存入方块实体 NBT；重进世界、区块重新加载、新一局回放后仍保留。旧存档缺少字段时补默认值。
- 服务端校验创造模式、存活、建造能力、维度、交互距离、已加载区块与目标方块。保存确认由服务端返回。
- 界面内提供本地地图「完整车体 / 动态扇形剖切」切换；该选项沿用本地观看设置，不写入木桌存档。

## 四幕播放（由服务端同步）

| 幕 | 呈现 |
| --- | --- |
| 发车准备 2.5s | 待机方块旋转收拢到托盘，金色光环向外扩散，接上沿地图长轴扫过的金色扫描面；微缩列车逐段显形，铭牌切到地图名和回放时钟 |
| 全员推演 16–24s | 立体头像沿样条平滑移动并轻跳，彗星拖尾 + 全程淡轨；击杀/命中/爆炸进入 0.35× 慢镜，地图推近特写并弹出事件简报条 |
| 终局复盘 3.5s | 金色结算波纹扫过整列火车，全部轨迹与节点定格 |
| 荣誉结算 8.5s | 沙盘下沉压暗，Art Deco 荣誉屏展开：胜方标题/副标题/印章、自转头像陈列（职业名、MVP 皇冠）、MVP 战绩、本局时长/总击杀/首杀与终结；最后约 2 秒荣誉屏折叠、地图反向收回，金圈聚到桌心，待机方块升起，灯带和铭牌恢复待机 |

- 荣誉屏在回放桌的最上层绘制，完整展开时遮住重叠的沙盘、桌角和灯饰，同时保留场景墙体的遮挡。
- 头像：内层 8×8×8 皮肤头 + 1.125× 外层帽子；在线玩家用实时皮肤，离线玩家异步拉取，未到达前用默认皮肤并自动热刷新。脚下圆环为职业色（死亡变灰，复盘时胜者为金色）。
- 状态：死亡下坠碎裂 → 小墓碑 + 半透明幽灵；复活金色光柱；伪装紫色重影与角标；疯魔暗红气焰；沉睡 `z Z`；停电区间整体压暗并泛红色应急光。
- 无人机操作者：独立记录每架无人机的部署、飞行、坠落和回收轨迹，沙盘用四旋翼模型显示，不影响玩家位置或结算。
- 节点：击杀猩红脉冲 + 斩击连线 + 悬浮 3D 凶器；弹道白金光束、枪口星芒、未命中火花、掉枪警示；爆炸/下毒/破盾/门锁/技能等各色光环。

## 事件特写与地图截断

- 操作发生时，以事件起点和终点的中点为特写中心，地图、头像、轨迹、武器和空间效果使用同一缩放与位移。托盘、铭牌、事件简报和荣誉屏保持原布局。
- 玩家立体头像的基础尺寸按地图原始跨度调整：紧凑地图更接近人物原比例，长地图也保留可辨认的尺寸。回放桌、历史 3D 预览和导出都按镜头透视限制屏幕占比，仍会随推拉改变大小；桌上事件的发起者和目标随特写平滑放大，旁观者不会获得额外放大。视频高光和 MVP 镜头应用同样的强调规则。
- 击杀优先，锁定倍率最高 2.4×；爆炸、命中、反噬、复活、拆弹最高 2.1×；下毒、破盾、埋弹、技能、陷阱、绳索最高 1.8×；投雷、伪装、转职、使用物品和开锁/撬门/封门最高 1.55×。普通开关门、锁门/解锁、停电状态变化不触发特写，避免频繁跳转。
- 远距离操作会自动降低倍率，把操作双方留在同一个镜头中。地图自动转 90° 时，特写焦点也同步转换。
- 推近用 0.3 秒的 Back 曲线：快速冲入、超过锁定倍率、回弹到位；倍率锁定至事件后约 0.8 秒，再用 0.7 秒四次缓入缓出退回全景。峰值略高于锁定倍率。全部按画面播放时间计时，慢动作不拉长特写动画。
- 前 0.3 秒保护当前镜头；随后连续关键事件从当前镜头位置和倍率接续。锁定期间低优先级操作不能抢走高优先级特写。同一时刻的多个事件以优先级最高者为准。
- 进入终局复盘前提前回到全景。
- 地图始终裁在固定托盘内沿内侧 0.04 格处。实体、镂空、流体和半透明地图层都在绘制时截断，头像皮肤、文字、武器、轨迹和光效也按同一托盘边界裁切。不同桌子的旋转、显示位置与尺寸均参与变换。原始地图数据保持完整，缩放不触发网格重建。

## 本地观看交互

空手右键看板：

- 右键打开控制界面，选择「播放一次」。有上一局记录时，每张桌子仍默认显示无对局数据时的待机动画。服务器按该桌所在维度的游戏时钟广播起点；同桌观看者同步看到四幕，中途靠近会接入当前进度。播放结束自动回到待机，期间重复点击不重开。每张桌子独立触发。
- 选择「导出视频」，客户端准备完整的已录地图快照，按独立的「导演剪辑」生成一段约 40–80 秒的短片（与木桌四幕循环分离）。导出界面可切换 **480P / 720P（默认）/ 1080P / 2K (1440P) / 4K (2160P)** 分辨率（左键下一档、右键上一档），并可开关「自动压制」（默认开启，内置 JCodec 纯 Java H.264 编码直出 `.mp4`；关闭时直出 Motion-JPEG `.avi`）；玩家上次选择的分辨率与压制开关保存在客户端本地配置 `config/habitrain_core-client.json` 中。视频为 30 帧/秒，保存到游戏目录的 `habitrain-replays/`。完成后点击「打开视频文件夹」。详见下文「视频导出（导演剪辑）」。
- 地图快照加载完成后即可开始导出。按 Esc 关闭导出页或新对局开始时，导出会在后台继续，屏幕右侧显示进度和操作提示。后台导出时再按 Esc 可取消，也可回到导出页点击「取消导出」。木桌和背包里的历史回放共用同一个客户端导出任务。
- 能打开 3D 回放的玩家都能收听录制的高光语音。导出时由服务器确认身份，参赛者和管理员可以导出玩家语音，其他观看者导出的视频保留游戏音效。授权后会等待完整语音，接收超时会提示重试。
- 非创造模式下潜行 + 右键：动态扇形剖切 ↔ 显示完整车体。创造模式下改为打开木桌设置，地图开关在设置界面内。

剖切以当前可见的回放头像为中心，朝观看者一侧展开 **80° 扇形开口**，并在头像附近保留圆角开口以露出正上方的车顶。头像移动、上下楼、死亡留碑或复活时，开口跟随当前回放姿态；离开或尚未出现的头像不产生开口。多个头像各自生成开口，取它们的并集，不再按整局统计高度水平削去整层车顶。每个开口只移除高于对应头像脚部的方块，不向下挖掉该头像的支撑地板；不同楼层的开口重叠时，上层结构也可能位于下层头像的开口内。

扇形方向取观看摄像机朝向的反向，并转换回地图本地坐标；绕桌观看、转头、桌子四向放置、地图自动转 90° 和显示设置的旋转都参与计算。垂直俯视时回退到观看者所在的地图侧面。该效果属于本地观看设置，各客户端可看到朝向自己展开的切口。

地图始终保留完整源数据。回放专用网格预留实体方块的相邻面，绘制时按方块中心判定扇形内外，切口呈贴合方块的阶梯边界，保留下来的方块显示实体表面。头像运动、转头和完整车体开关只更新绘制参数，不重建地图；其他移动场景仍使用原有的面裁剪方式。车窗、流体与第三方特殊模型沿用原有烘焙路径。

## 资源生命周期

- 所有看板共用一份 `SceneMeshSet`；按「地图指纹 + 已到 Section 数」重建，补齐期间合并为最多每 2.5 秒一次，最终完整时立即重建。各看板分别计算观看方向，不因切口变化重新提交地图构建。预留的实体相邻面会增加网格大小，仍受原有网格配额保护。
- 对局结束或采集超时时，仍会展示已采到的地图区段，并保持对局区域的比例。没有采到可用区段时，仍可看轨迹和荣誉结算。
- 断开连接、切换维度/世界、资源重载、新局换图时取消在途构建并 `close()` 旧网格；迟到结果直接关闭；45 秒未渲染任何看板时自动释放显存。

## 视频导出（导演剪辑）

导出的视频不再录制木桌的四幕循环，而是由纯函数剪辑表 `ReplayVideoScript` 逐帧决定时间、镜头、3D 特效与 2D 动态图形，因此任意帧都可复现。

| 幕 | 时长 | 内容 |
|----|------|------|
| 片头 | 3.6 s | 星空背景淡入，品牌标识；「回放车票」从下方滑入（终点站=地图名、模式、日期、时长、乘客数、车次），盖上「已检票」印章；吊臂镜头下降，沙盘扫描成型 |
| 对局 | 自适应 | 列车发车标题；高光之间超速快进（右上角倍速芯片 + 箭头），每个高光：镜头跟随出手者推进 → 事件帧定格 + 子弹时间环绕 + 推镜冲击与震屏 → 慢镜余韵后拉回 |
| 复盘 | 4.2 s | 上帝视角升起，全员轨迹与金色复盘波；对局时长 / 总击杀 / 参赛乘客 / 高光数计数动画 |
| 胜利 | 4.0 s | 胜方配色神光与笔刷横幅，VICTORY 标题砸入，获胜方头像依次弹出（MVP 戴冠），彩带 |
| MVP | 5.6 s | 镜头偏左环绕 MVP 模型（3D 聚光柱 + 旋转光环 + 皇冠），右侧六边形勋章肖像、桂冠、得分/击杀/存活/道具计数与比例条 |
| 片尾 | 6.4 s | 「乘客名单」计分板（胜方高亮、MVP 皇冠），首杀/终结信息、品牌落款，淡出 |

- **高光选取**：击杀、复活、爆炸（手雷/炸弹）、拆弹、破盾、枪械命中按分数选取，最多 10 个、彼此至少相隔 24 tick；首杀、连杀（同一玩家 30 秒内连续击杀：双杀 / 三杀 / 多杀）与终结一击加权。未入选的击杀和其余事件进入右侧事件流（门的开/关不显示）。
- **专属效果**：击杀（光柱、三重冲击波、受重力碎片、焦痕、弹道曳光、锁定准星、红色闪屏与集中线）、复活（金色双螺旋、光环升至头顶、八芒星地纹）、爆炸（火球、烟环、冲击环、火星）、拆弹（六边形护罩）、破盾（六边形碎片）、下毒（气泡）、伪装（紫烟）、转职（职业色光环上升）、技能（符文法阵）、陷阱（尖刺合拢）、绳索/投掷（抛物线与飞行光点）、狂暴（红色放射与屏幕边缘脉冲）、停电（黑波扫过、扫描线与闪烁）、开锁/撬门/封门（门框脉冲）、使用道具（闪光）。效果按视频时间播放，定格期间冲击仍在继续。
- **层次**：背景层（渐变夜空、视差星云、三层星点、舞台背光、胜利/MVP 神光）→ 3D 层（地台光池、漂浮尘埃、沙盘与特效）→ 前景层（反向视差散景、调色、暗角、胶片颗粒、电影遮幅、冲击闪光）→ 界面层（HUD、卡片、锚定在 3D 位置的标注、转场斜切）。冲击帧在编码线程上附加色散。
- **素材**：`assets/habitrain_core/textures/replay_video/` 下的贴图由 `tools/replay_video_assets/gen_assets.py` 程序化生成，可重新运行；Latin 字形使用随包的 Bebas Neue / Oswald（SIL OFL 1.1，见 `font/replay/NOTICE.txt`），中文回退到游戏默认字体。

## 验收建议

1. 放置四个朝向的看板，确认待机和回放时沙盘底座俯视均为正方形，地图比例正常，铭牌、沙盘与荣誉屏都正对放置者，木桌碰撞箱与模型一致。
2. 无上局时显示悬浮于星轨罗盘之上的多重交叠旋转 3D 正方体全息阵列与「暂无上局对局记录 · 等待发车」。
3. 两台客户端同时看同一张待机桌。一人点击播放，比对同一时刻的头像位置、慢镜与荣誉屏，并确认结束后都回到待机、另一张桌子仍在待机。
4. 断线重连、F3+T 资源重载、切维度后无报错且画面恢复。
5. 创造模式 Shift + 右键（分别空手、持方块）打开 UI：把地图长边保存为 3 格后开播，确认全景地图长边为 3 格，沙盘底座开播前后没有跳变。再调高度、偏移与旋转，确认地图与人物/轨迹对齐，承托光束保持连接真实桌面。取消应恢复原显示。
6. 两张桌子分别保存不同设置；重新进世界后仍独立保留，另一客户端与稍后加入的客户端看到相同结果。非创造模式不出现设置 UI。
7. 回放头像行走和上下楼时，开口中心及底部跟随头像，身后和扇形外的地图恢复；多个楼层同时有人时检查各处开口及重叠区域。死亡标记继续可见，离开玩家的切口消失。
8. 绕桌四侧、转头和垂直俯视，确认开口向观看者展开；分别调整旋转、偏移和尺寸，地图与头像的切口仍对齐。两台客户端从相反方向观看，应看到不同方向的本地切口。
9. 切换完整车体后地图恢复，再切回可立即剖切，无需等待地图重建。
10. 击杀、枪械命中、爆炸、技能或使用物品时，确认地图快速推近、过冲回弹、短暂停留后退回；事件双方及地图上的头像/武器/轨迹对齐。连续击杀镜头连续接续，物品操作不抢走击杀特写。
11. 放大后绕托盘四边检查：地图、半透明车窗和轨迹在内沿截断，不越出托盘。调整四向放置、显示旋转、尺寸和偏移后重复检查；远距离击杀应保留双方并自动降低倍率。
12. 记录包含无人机部署、飞行、坠落与回收的一局；验证回放里的无人机与操作者独立移动，导出视频能播放，无人机与模型可见，进度和文件夹按钮正常。
13. 导出包含首杀、连杀、复活、爆炸、停电与狂暴的一局：确认片头车票、每个高光的定格/慢镜/标题卡/击杀卡与 3D 标注对得上事件双方，事件流、存活计数、时间轴标记与比赛时钟一致，胜利、MVP 与乘客名单数据正确。

### 背包里的历史 3D 回放（API 2.0.37 / 抽奖补齐 1.1.66）

自 API 2.0.38 起，桌旁回放声音按距离播放，背对正在播放的桌子也能听到。放大或偏移沙盘时，显示和读取回放使用相同的距离规则。完整地图构建失败会明确报错，可重试，不会用缺块的模型导出。

历史语音不可用时仍可播放地图、导出带游戏音效的视频。客户端的对局摘要和已收听语音共用 64 MiB 磁盘配额，最多保留 30 天；可在「回放存储」中清除本地历史缓存，不影响服务器存档和已导出的视频。导出时音频在后台按一秒为单位混音。

- 背包 → 对局记录 → 选中一局。用「查看 3D 回放」拖动旋转、滚轮缩放、拖时间轴；用「导出视频」选择 MP4 / AVI 与分辨率，视频生成在客户端游戏目录的 `habitrain-replays` 中。
- 3D 页可把该局共享到 16 格内最近的一张回放桌。桌旁玩家会先按需接收地图和轨迹，再按服务端下发的同一起播时间播放一次。若有人一直未就绪，最长准备 3 分钟，后到的玩家会跟上当前进度。
- 服务器存档位于世界目录下的 `habitrain/replay-archive`。Mod Menu → 哈比列车核心 → 回放存储 可查看用量、目录和默认 5 GiB 上限；管理员可修改。超限只淘汰最早的 3D 回放，原有文字对局记录不变；相同的地图快照只存一份。
- 装有 Simple Voice Chat 时，服务器默认录制对局高光附近的语音。管理员可在「回放存储」关闭录制。关闭时丢弃本局尚未保存的语音，已有回放仍可播放；重新开启后从下一局开始录制。
- 升级前没有记录完整地图和轨迹的旧场次不能补出 3D 回放。快速结算时若存档还在准备，可在 3D 页重试。
